Управление проактивностью

Глобальный выключатель

Останавливает все фоновые обращения агента немедленно, во всех командах. Стендапы по расписанию тоже перестают писать в чат.

Лимиты (из .env, требуют перезапуска)

  • PROACTIVE_MAX_PER_DAY = {{ cfg.PROACTIVE_MAX_PER_DAY }} — проактивных сообщений в сутки на команду, не считая стендапа
  • QUIET_HOURS_START/END = {{ cfg.QUIET_HOURS_START }}:00–{{ cfg.QUIET_HOURS_END }}:00 — в тихие часы сообщения копятся и уходят утром
  • RISK_SCAN_CRON = {{ cfg.RISK_SCAN_CRON }}
  • STANDUP_COLLECTION_HOURS = {{ cfg.STANDUP_COLLECTION_HOURS }}
  • PROPOSAL_EXPIRY_DAYS = {{ cfg.PROPOSAL_EXPIRY_DAYS }}
  • DAILY_MESSAGE_LIMIT_PER_TEAM = {{ cfg.DAILY_MESSAGE_LIMIT_PER_TEAM }}
